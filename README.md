  # Swiggy Sales Dashboard

# Project Overview:
This project analyzes Swiggy sales data using Microsoft Excel. The dashboard provides a visual representation of sales performance, customer ratings, food categories, and city-wise sales.

# Problem Statement:
Manually analyzing Swiggy sales data can be time-consuming and may make it difficult to identify sales trends and top-performing cities. This project aims to develop a Microsoft Excel dashboard that enables users to analyze sales performance, customer ratings, food categories, and city-wise sales efficiently.

# Project Objectives:
- Analyze overall sales performance.
- Understand monthly and daily sales trends.
- Compare Veg and Non-Veg sales.
- Identify the top five cities by sales.
- Analyze customer ratings and order values.
- Explore sales data using interactive filters.

# Tools and Technologies Used:
- Microsoft Excel
- Pivot Tables
- Charts
- Data Visualization
- Slicers
- Excel Formulas

# Key Performance Indicators (KPIs):
- Total Sales: ₹53.01M
- Average Order Value: ₹268.51
- Average Rating: 4.34
- Rating Count: 55,91,574
- Total Orders: 1,97,430

# Dashboard Features:
- Monthly sales trend
- Daily sales trend
- Sales by food type, including Veg and Non-Veg
- Top five cities by sales
- Interactive slicers for months, categories, and restaurant names
- KPI cards for sales and order analysis

# Key Insights:
- Bengaluru has the highest sales among the top five cities displayed.
- New Delhi has the lowest sales among the top five cities displayed.
- Veg food accounts for 95% of sales, while Non-Veg food accounts for 5%.
- Saturday has the highest daily sales among the days displayed.
- Tuesday has the lowest daily sales among the days displayed.
- Monthly sales fluctuate across the months shown.
- Sales performance varies across different food categories.
- Interactive slicers allow users to filter data by month, category, and restaurant name.
